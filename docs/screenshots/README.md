Erzeugt mit `lindenweg16-legal-suite/tests/e2e/tools/screenshots.mjs` gegen die Testinstanz (siehe `docs/testen.md`). Das Theme ist das WordPress-Standardtheme, nicht dein Theme: Schriften, Farben und Abstände sehen bei dir anders aus. Beurteilen lassen sich Inhalt, Position und Reihenfolge der Plugin-Elemente.

- `A1`–`A5`: Vorher (Plugin-Module aus) / Nachher
- `01`–`05`: Cookie-Banner (Desktop, Einstellungen, Handy, dunkel)
- `09`–`11`: Checkout-Fehler und Bestätigung
- `12`–`17`: Widerruf (Formular, Fehler, Prüfen, Bestätigt, Handy, Mails)
- `18`–`21`: Kontakt und Newsletter
- `22`–`24`: Rechtstexte und Footer
- `25`–`30`: Admin
